# Python / AI 练习区

这里专门放学习练习，**不要**改 `app/` 里的业务代码。

## 怎么跑

项目根目录已有 `.venv`。在仓库根目录执行：

```bash
source .venv/bin/activate
python lessons/pcc/ch02/2_1_simple_message.py
```

书上的练习按章放在 `lessons/pcc/chXX/`，一题一个文件。第 01 课已经完成。

## 学习路线

计划依据《Python编程：从入门到实践》第 3 版，章节、必做练习和章末检查见 [plan.md](./plan.md)。

1. 书的第 2–11 章（第 1 章的环境已经有了；第 01 课只覆盖了列表推导的一种写法）
