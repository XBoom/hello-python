# 学习计划

主线是一本书，不是一份只有课名的大纲。

**书：** Eric Matthes，《Python Crash Course》第 3 版。中文版书名是《Python编程：从入门到实践》（第 3 版）。  
目录以出版社公开的详细目录为准：[PCC 3e detailed TOC](https://nostarch.com/download/PCC3e_detailedTOC.pdf)。中英文版页码不同，按**章节名和练习编号**找，不按页码。

选这本书，是因为它把「读一节、做编号练习」写成了固定节奏，和第 01 课的做法一致：先看例子，再自己写，跑通才算完。它不覆盖类型标注、`async`、NumPy、Pandas 和本仓库的 FastAPI。这些放在书的对应章节之后，单独列出来，不假装书里有。

## 怎么用

1. 只读当前这一章里列出的节。读完一节，立刻做这一节后面的练习。
2. 练习写在 `lessons/pcc/chXX/`，一题一个文件，例如 `lessons/pcc/ch02/2_3_personal_message.py`。
3. 在仓库根目录运行该文件。需要打印的题，看终端输出是否符合你在文件顶部写下的预期。需要 `assert` 的题，断言失败就改代码，不改断言。
4. 这一章的必做练习都通过后，再做该章的**章末检查**。检查文件在你开始这一章时再创建，避免提前看到写法。
5. 章末检查出现「练习也通过」才进入下一章。
6. 卡住时只问当前这几行。先留一个会报错的版本，看报错再改。
7. 第 11 章结束前不打开 `app/`。
8. 每一章的语言练习做完后，再做该章的工程一步。工程一步使用本仓库已经写好的工具和规范，不另起一套流程。

书教语言。下面这些事按章加上，依据是 `docs/python.md`、`docs/git.md`、`docs/testing.md`、`docs/security.md`。没到的章不做。
